# カインとアベル - 画像・動画生成ガイド

## 1. キャラクターの準備
`character_prompts.md` を参考に、Midjourneyでカインとアベルの基本スタイルを生成し、キャラクターリファレンス（--cref）用の画像を用意してください。

## 2. 画像の生成
`scene_prompts.json` のリストに従って、各シーンの画像を生成してください。
- 神様単独のシーン (4-1, 4-2, 5-3, 6-1, 6-4) は生成不要です。既存の `adam_and_eve` アセット（シーン1-2.jpegなど）を流用します。
- 生成した画像は `cain_and_abel/images/` フォルダに保存し、ファイル名を `シーンX−Y.jpeg` の形式で保存してください。

## 3. 動画の生成
`video_prompts.json` のリストに従って、Luma Dream Machineで動画を生成してください。
- 指定された画像（シーンX-Y.jpeg）を入力として使用します。
- 生成した動画は `cain_and_abel/videos/` フォルダに保存し、ファイル名を `シーンX−Y.mp4` の形式で保存してください。

## 4. アプリへの組み込み
`app_data.js` の内容をメインアプリケーションのデータ構造（`src/data/themes.js` など）に追加してください。
神様流用シーンのパスが正しく指定されていることを確認してください。
