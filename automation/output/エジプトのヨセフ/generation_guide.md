# エジプトのヨセフ (joseph_in_egypt) 画像生成ガイド

## 概要
このガイドは、「エジプトのヨセフ」の絵本用の画像および動画をLuma Dream Machine (またはMidjourney等の画像生成AI) で生成するための手順書です。

## 注意事項
- **神様単独のシーン（2-1, 4-2）は画像を生成しません**。`./assets/adam_and_eve/images/シーン1−2.jpeg` などの既存画像をアプリ内で流用します。
- 画風は「水彩画風 (Watercolor)」「パステルカラー」「手描きテクスチャ」「光の粒子」をベースにしています。
- キャラクターの顔立ちは「大きくて表情豊かな瞳」「シンプルで丸みを帯びた輪郭」に統一してください。

## 生成手順
1. `scene_prompts.json` に記載されているプロンプトを使用して、各シーンの静止画を生成します。
2. 生成した静止画のうち、`video_prompts.json` に記載されているシーンについては、Image-to-Video機能を使って動画（mp4）を生成します。その際、`video_prompts.json` のプロンプトをテキストプロンプトとして併用してください。
3. 生成したファイルは、以下の命名規則で保存してください。
   - 静止画: `シーン{X}-{Y}.jpeg` (例: `シーン1-1.jpeg`)
   - 動画: `シーン{X}-{Y}.mp4`
4. カバー画像は `シーン0-1.jpeg` として保存します。

## キャラクター設定の参考
必要に応じて、`character_prompts.md` に記載されている各キャラクターの詳細プロンプトを参照し、一貫性を保つようにしてください。
