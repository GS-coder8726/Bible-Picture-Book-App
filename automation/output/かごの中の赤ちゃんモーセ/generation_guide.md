# 画像・動画生成ガイド：かごの中の赤ちゃんモーセ (baby_moses)

## 1. はじめに
本ドキュメントは「かごの中の赤ちゃんモーセ」の画像および動画を生成するためのガイドラインです。
全てのアートスタイルは「adam_and_eve」などの既存テーマとトーンを合わせるため、「水彩画風 (Watercolor)」「パステルカラー」「光の粒子 (Sparkles)」を基調としてください。

## 2. 特別ルール（神様の表現）
**以下のシーンについては、画像を新規生成しないでください。**
既存の「adam_and_eve」のアセット（シーン1-2など）をそのまま流用します。
- **対象シーン**: `1-4`, `2-4`, `6-1`, `6-4`

## 3. 画像生成の手順 (Midjourney 等)
1. `scene_prompts.json` に記載されたプロンプトをそのまま使用して画像を生成してください。
2. アスペクト比は横長（例: `--ar 16:9`）を指定してください。
3. 全体的に「温かみのある」「夢のような」雰囲気（Dreamlike atmosphere, warm and cozy）になるよう、必要に応じてプロンプトを微調整してください。
4. キャラクターの顔立ちが複雑になりすぎないよう、シンプルで丸みを帯びたデザイン（Simple soft rounded features, chibi-like proportions）を維持してください。

## 4. 動画生成の手順 (Runway, Luma 等)
1. `video_prompts.json` に記載されたシーンのみ動画化を行います。
2. 生成した静止画をベースに、プロンプトの指示（Gentle slow-motion, subtle animation 等）に従って微細な動き（服の揺れ、水面の波紋、光の瞬き）を加えてください。
3. 激しい動きは避け、幼児が落ち着いて見られるゆったりとしたアニメーションにしてください。

## 5. 出力ファイルの配置
- 画像: `./assets/baby_moses/images/シーン{id}.jpeg`
- 動画: `./assets/baby_moses/videos/シーン{id}.mp4`
