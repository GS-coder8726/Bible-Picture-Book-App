# アブラハムとイサク (abraham_and_isaac) 絵本画像・動画生成ガイド

## 1. 概要
- **テーマ**: アブラハムとイサク
- **シーン数**: 全26シーン
- **動画シーン数**: 13シーン
- **神様シーン**: 4シーン (既存画像を利用: 2-1, 2-2, 6-1, 6-2)

## 2. 生成手順 (Midjourney / DALL-E)
1. `scene_prompts.json` のプロンプトを使用して、神様以外の各シーンの画像を生成してください。
2. アートスタイルは「Watercolor style illustration」「Soft pastel colors」「Glowing light particles」が必須です。
3. リファレンス画像（キャラクターの画風など）を踏襲して、絵のトーンを統一させてください。
4. 神様が登場するシーン（2-1, 2-2, 6-1, 6-2）は、`./assets/adam_and_eve/images/シーン1−2.jpeg` または `./assets/adam_and_eve/images/シーン5−1.jpeg` を流用するため、新しく生成する必要はありません。

## 3. 動画生成手順 (Luma / Runway / Kling)
1. `video_prompts.json` に記載されているシーンに対して、生成した静止画を元に動画を生成してください。
2. カメラの動きはゆっくりとしたパンやズーム、キャラクターの微細な動き（まばたきや風になびく髪など）を指定してください。
