# 画像生成・動画生成の手順書 (ノアのはこぶね)

## 1. キャラクターの準備
`character_prompts.md` に記載されたプロンプトを使用して、ノアや動物たちのベースとなる画像を生成してください。
※神様の画像は `adam_and_eve` から流用するため、生成不要です。

## 2. シーン画像の生成
`scene_prompts.json` のプロンプトを使用して、各シーンの画像を生成します。
生成した画像は `./assets/noahs_ark/images/シーン{id}.jpeg` という名前で保存してください。

## 3. 動画化
`video_prompts.json` に記載されたシーン（全シーンの約50%）について、生成した静止画を元に動画化ツール（KlingAIやLuma Dream Machineなど）を使用して動画を生成します。
生成した動画は `./assets/noahs_ark/videos/シーン{id}.mp4` という名前で保存してください。

## 4. データの組み込み
1. 画像・動画ファイルが全て揃ったら、`app_data.js` の内容をメインアプリケーションのデータ構造（`app.js` など）に追加します。
2. その際、神様のシーン（1-3, 4-5, 6-4）は既存の `adam_and_eve` の画像パスを指定していることを確認してください。
